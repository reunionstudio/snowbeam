# Snowbeam 0.2.0a5 validation

Checked in an isolated Linux development environment, 2026-10-14, using mocked
Snowflake and vault CLIs unless noted.

## Source checks

- Ruff lint and formatting checks passed.
- 146 automated tests passed on Python 3.12, including:
  - Full PAT lifecycle: plan, apply, vault write, verify, rotate, retire-old,
    revoke, stale approval rejection, vault failure rollback, and PAT mint
    uncertainty recovery.
  - KEYPAIR provisioning and dual-slot rotation without overwriting unmanaged keys.
  - WIF provisioning without vault access; revoke clears workload binding.
  - Runtime bundle export, tamper detection, operator-supplied test reports, and
    `runtime exec` isolation from the manager configuration.
  - Vault adapters for 1Password and Bitwarden: stdin/base64 payloads, read-back
    verification, ambiguous field rejection, and credential session hygiene.
  - CLI `identities plan` / `identities apply` JSON wiring and Bitwarden template
    provisioning.

## What was not exercised here

- No live Snowflake account, real `snow` provisioning statements, or actual
  `op` / `bw` writes in this run.
- No cloud workload identity authentication on AWS/GCP/Azure hardware.
- No Omarchy or macOS desktop integration trial.
- Hosted GitHub Actions CI remains a setup template only.

Use a dedicated Snowflake test account and your real vault CLIs before relying on
managed agent lifecycle in production. The tests prove the local state machine and
command sequencing; they do not replace account-specific policy review.
