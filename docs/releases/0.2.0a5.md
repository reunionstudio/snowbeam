## Managed agent lifecycle

The working source already implements the full manager-side path:

1. Define an account-bound template (`templates add`) with role, policies, and
   authentication method (PAT, KEYPAIR, or WIF).
2. Record agent intent (`identities add`).
3. Review `identities plan` (or **Enter** / `p` on Identities in the terminal app).
4. Apply with the exact approval digest from that plan.
5. Save the one-time `credential_relay` output in your password manager, then
   `identities confirm-relay` and `identities verify` with `--token-file` or
   `--private-key-file` from the declared runtime.
6. Rotate, retire the previous credential, or revoke through the same plan/apply
   flow.

Optional: `snowbeam preferences vault-integration on` and template vault fields
restore automated 1Password/Bitwarden writes for teams that opt in. See the
[identity and security guide](../security.md).

### Try it (manager machine)

Prerequisites: Snowflake CLI (`snow`) with an administrative connection,
OpenSSL for key pairs, and `op` or `bw` unlocked for the template's vault.

```sh
snowbeam templates add acme-reporting \
  --organization ACME --account PROD --admin-connection acme-admin \
  --role REPORTING_AGENT --authentication-policy SECURITY.POLICIES.AGENT_PAT_ONLY \
  --network-policy REPORTING_RUNNERS --auth PAT --days-to-expiry 30 \
  --provider onepassword --vault VAULT_ID --vault-account ACCOUNT_ID

snowbeam identities add sam --template acme-reporting --user AGENT_SAM \
  --client Acme --owner Jane --runtime runner-east

snowbeam identities plan sam --json
snowbeam identities apply sam --approve APPROVAL_DIGEST_FROM_PLAN --json
snowbeam runtime export sam --out sam-runtime.json
```

On the runtime: `snowbeam runtime test sam-runtime.json --out sam-test.json`,
then return the report for `identities accept-test`.

## Install or upgrade

On macOS, install with `brew install reunionstudio/tap/snowbeam`. Existing official
Homebrew installations can use **Updates → Check now → Update and restart**, or
close Snowbeam and run `brew update` and `brew upgrade reunionstudio/tap/snowbeam`.

On Linux or Omarchy with uv:

```sh
uv tool install --reinstall https://github.com/reunionstudio/snowbeam/releases/download/v0.2.0a5/snowbeam-0.2.0a5-py3-none-any.whl
snowbeam --version
```

This remains an alpha. Automated tests cover plan generation, apply steps, vault
verification, rollback/recovery, and runtime handoff with mocked Snowflake and
vault CLIs. Hosted Linux CI, live Snowflake/vault trials on every platform, cloud
workload authentication on a real cloud runtime, and actual Omarchy desktop
validation remain pending.
