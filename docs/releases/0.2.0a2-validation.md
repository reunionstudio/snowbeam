# Snowbeam 0.2.0a2 validation

Checked on macOS ARM64, 2026-09-13, using isolated synthetic data.

## Source checks

- Ruff lint and formatting checks passed.
- All 136 tests passed on Python 3.11.15, 3.13.15, and 3.14.3.
- Label tests cover migration from inventory schema 3 to 4, persistence after
  refresh and restart, account renames recognized by locator/region, distinct
  account IDs, clearing one field without changing the other, invalid control
  characters and field lengths, and offline CLI editing and JSON output.
- Terminal tests exercise organization and account forms, save and cancel,
  selection after saving, literal square brackets, multiline notes, alias search,
  unchanged profile files, and copying the real account identifier.
- The editor was tested at 80 × 24, including scrolling to Save by keyboard.
  Demo captures were regenerated; the editor and inventory were visually inspected.

## Distribution checks

Artifacts were built from source commit `7b66be9314063c1307ff66b93c2364016ca64933`,
tagged `v0.2.0a2`. The published artifacts were not replaced after validation.

- Wheel and source archive passed strict metadata checks and separate clean
  installs outside the checkout: version, bundled icons, synthetic inventory,
  and headless terminal startup all passed.
- A real wheel upgrade from 0.2.0a1 retained synthetic connection configuration,
  identity configuration, token metadata, and operation history. The schema-4
  inventory then stored and reopened organization/account annotations.
- All four public release assets downloaded without authentication. Wheel and
  archive SHA-256 checksums matched the local verified artifacts; the downloaded
  formula matched the generated formula. The public wheel URL installed through
  uv into an isolated tool directory on this Mac.
- Homebrew tap commit `7c52edc` installs this release. The installed 0.2.0a1 app's
  actual **Check now** and **Update and restart** controls discovered 0.2.0a2,
  upgraded through Homebrew, and reopened the app with the same isolated
  inventory and configuration. The reopened app displayed the new Alias / notes
  control and opened the organization editor.
- The installed 0.2.0a2 CLI saved organization and account aliases and notes;
  reopening the store retained multiline notes, original identifiers, and the
  earlier operation journal. Automatic update checks remained off. No real
  Snowflake connection or user inventory was used in this trial.
- `brew test reunionstudio/tap/snowbeam` passed. Homebrew developer mode was
  restored to its original disabled setting after the test.
- The website's static link check passed and its published Snowbeam HTML matched
  the checked source, including the alias description and 0.2.0a2 wheel URL.

Omarchy desktop was used. Hosted Linux CI, Intel macOS, and real Linux desktop
validation remain pending. The portable wheel and platform-specific integrations
