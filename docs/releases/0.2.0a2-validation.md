# Snowbeam 0.2.0a2 validation

Checked on macOS ARM64, 2026-09-13, using isolated synthetic data.

## Source checks

- Ruff lint and formatting checks passed.
- All 136 tests passed on Python 3.11.15, 3.13.15, and 3.14.3.
- Label tests cover migration from inventory schema 3 to 4, persistence after
  refresh and restart, account renames recognized by locator/region, distinct
  account IDs, clearing one field without changing the other, invalid control
  characters and field lengths, and offline CLI editing and JSON output.
- Terminal tests exercise organization and account forms, save and cancel,
  selection after saving, literal square brackets, multiline notes, alias search,
  unchanged profile files, and copying the real account identifier.
- The editor was tested at 80 × 24, including scrolling to Save by keyboard.
  Demo captures were regenerated; the editor and inventory were visually inspected.

## Distribution checks

Release artifacts are checked after the source commit using `tools/check_release.py`.
The real wheel upgrade is checked with `tools/check_upgrade.py`. Public download,
Homebrew upgrade, and installed-app results are recorded here after publication.

## Remaining limits

No live Snowflake account, real vault write, cloud workload authentication, or
Omarchy desktop was used. Hosted Linux CI, Intel macOS, and real Linux desktop
validation remain pending. The portable wheel and platform-specific integrations
are covered by local tests, which do not substitute for those environments.
