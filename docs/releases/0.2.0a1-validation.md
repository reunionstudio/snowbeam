## Homebrew test scope

The local trial installed the previous prepared alpha, then
used `brew upgrade` to install the candidate as disposable
formula revision 1. This trial preceded the in-app installer implementation.
Both report package version `0.2.0a1`; no fictitious version or revision was
published. The trial verified SQLite migration, retained configuration and
operation history, installation detection, and the version-independent reminder
command. A separate `tools/check_upgrade.py` run replaced the old wheel with the
candidate in an isolated Python 3.13 environment and checked the same retained
data. All data was synthetic, with no Snowflake calls or vault access.

This Mac's Homebrew dependency installation hit an existing ca-certificates link
conflict. The baseline trial used `--ignore-dependencies`; the local upgrade
formula omitted its dependency declaration and used the existing Python 3.13.13.
The production formula retains the Python dependency and locked resources. Its
standard build environment and selected `python3.13` command were exercised. Full
dependency resolution on a clean machine remains pending in the Homebrew CI job.
The disposable installation and tap are removed after validation.

The new in-app installer has isolated UI and command-runner tests. They exercise
success, failed installation, stale package metadata, stable/prerelease selection,
safe progress, timeout handling, and reopening with the same configuration. The
installer is eligible only for the official tap. An end-to-end button update
between two published versions from that tap remains pending; the earlier
command-line Homebrew trial is not evidence of that flow.

- If PyPI distribution is enabled later, configure Trusted Publishing and the
  protected `pypi` GitHub environment first. GitHub and Homebrew do not require it.
- Complete the live validation recorded in [releasing](../releasing.md) before
  making stable-release or validated-integration claims.

No real Snowflake account, vault, cloud runtime, desktop launcher, or reminder job
was modified during the earlier preparation. Its disposable Homebrew trials
preserved the user's existing uv installation.
