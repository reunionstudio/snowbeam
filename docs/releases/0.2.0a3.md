# Snowbeam 0.2.0a3

The tree heading is **Organizations** and the CLI inventory heading is **Accounts**.
Empty-state guidance and synthetic app captures use the same wording.

This release changes labels only. Organization/account aliases, notes, connection
settings, and local inventory retain their existing behavior and storage format.

On macOS, use **Updates → Check now → Update and restart** in the official Homebrew
installation, or close Snowbeam and run:

```sh
brew update
brew upgrade reunionstudio/tap/snowbeam
```

For a new macOS installation, use `brew install reunionstudio/tap/snowbeam`.
On Linux or Omarchy with uv, install or upgrade with:

```sh
uv tool install --reinstall https://github.com/reunionstudio/snowbeam/releases/download/v0.2.0a3/snowbeam-0.2.0a3-py3-none-any.whl
```

This remains an alpha. The [previous release validation](0.2.0a2-validation.md)
documents the tested update path and integration limits. Live Snowflake and vault
validation, hosted Linux CI, and actual Omarchy desktop validation remain pending.
